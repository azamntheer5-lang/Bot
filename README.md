# 🤖 بوت أم رهام — خدمات طلابية متكاملة

يوزربوت تيليجرام (GramJS) يعمل 24 ساعة وينشر **رسائل ترويجية متنوعة** تلقائياً في القناة،
مع محرك رشق أعضاء (سحب من مجموعات طلابية + إضافة للقناة) وتحويل واتساب للاستقبال.

---

## ⚙️ المتطلبات

- حساب تيليجرام مفعّل (الجلسة تُصدَّر مرة واحدة كسلسلة `SESSION_STRING`)
- بيانات تطبيق من [my.telegram.org](https://my.telegram.org) (`api_id` و `api_hash`)
- [حساب Render](https://render.com) مجاني + هذا المستودع على GitHub

---

## 🚀 النشر على Render خطوة بخطوة

### 1) ارفع هذا الكود إلى GitHub
مستودع فارغ باسم `Bot` — الكود في الجذر مباشرة (لا تضعه داخل مجلد فرعي).

### 2) أنشئ الخدمة
1. ادخل [dashboard.render.com](https://dashboard.render.com) وسجّل الدخول **بحساب GitHub نفسه**
2. اضغط **New +** ← **Web Service**
3. اختر مستودع `Bot` ← **Connect**
4. Render سيكتشف **Dockerfile** تلقائياً — لا تغيّر شيء في Build

| الإعداد | القيمة |
|---|---|
| Name | `um-raham-bot` |
| Region | Frankfurt |
| Instance Type | **Free** |

### 3) أضف متغيرات البيئة (Environment)
من نفس الصفحة، قسم **Environment Variables** — أضفها واحداً واحداً (انسخ القيم من صاحب المشروع):

| المفتاح | القيمة | ملاحظة |
|---|---|---|
| `API_ID` | رقم التطبيق | من my.telegram.org |
| `API_HASH` | نص التطبيق | من my.telegram.org |
| `PHONE` | `+967739407274` | رقم الحساب |
| `SESSION_STRING` | سلسلة الجلسة | ⚠ **سرّي جداً — لا تشاركه** |
| `WA_NUMBER` | `967770309310` | رقم واتساب الاستقبال |
| `TARGET_PEER` | `-1003551074029` | معرف القناة |
| `TARGET_ID` | `3551074029` | المعرف الخام |
| `TARGET_ACCESS_HASH` | `-7704087514161962884` | مفتاح الوصول |
| `TARGET_TITLE` | `ام رهام خدمات طلابية متكاملة` | اسم القناة |
| `POSTER_ON` | `true` | انطلاق الناشر تلقائياً |
| `POSTER_INTERVAL_MIN` | `50` | أقل فاصل (دقيقة) |
| `POSTER_INTERVAL_MAX` | `110` | أعلى فاصل (دقيقة) |
| `POSTER_DAILY_LIMIT` | `18` | سقف الرسائل باليوم |

### 4) أنشئ الخدمة
اضغط **Create Web Service** وانتظر البناء (2–3 دقائق) — ستظهر علامة ✅ Live.

### 5) تأكد أن البوت حي
افتح الرابط:
```
https://um-raham-bot.onrender.com/api/health
```
يجب أن ترى JSON فيه `"ok": true` وبيانات الحساب 🇸🇦.

### 6) ⚠ مهم جداً — منع النوم (الخطة المجانية)
الخطة المجانية تنام بعد 15 دقيقة بلا زوار فيتوقف البوت. الحل: موقع [UptimeRobot](https://uptimerobot.com):
1. سجّل حساباً مجانياً
2. **Add New Monitor** ← النوع **HTTP(s)**
3. الـ URL: `https://um-raham-bot.onrender.com/api/health`
4. الفاصل: **5 minutes** ← Save

بهذا يستيقظ البوت دائماً وينشر على مدار الساعة. ✅

## 🔄 كيف يعمل البوت؟

- عند الإقلاع يقرأ `SESSION_STRING` ويتصل بتيليجرام فوراً (بدون رمز تحقق)
- الناشر التلقائي يرسل رسالة متنوعة كل 50–110 دقيقة (سقف 18/يوم) وكلها تحمل رابط واتساب
- كل الإعدادات/الرسائل قابلة للتعديل عبر واجهة API (انظر الأسفل)

> **ملاحظة الخطة المجانية:** القرص مؤقت — عند كل نشر جديد تعود البيانات من متغيرات البيئة
> تلقائياً (الجلسة، القناة، واتساب، الناشر). حوض الأعضاء المسحوبين يُفرغ — أعد السحب عند الحاجة.

## 🧰 واجهة API (مختصرة)

| المسار | الوظيفة |
|---|---|
| `GET /api/health` | حالة الخدمة والاتصال |
| `GET /api/me` | معلومات الحساب |
| `GET /api/poster/status` | حالة الناشر التلقائي |
| `POST /api/poster/now` | انشر رسالة فوراً |
| `GET /api/poster/messages` | قائمة الرسائل |
| `GET /api/target` | القناة الهدف |
| `GET /api/campaign/status` | حالة حملة الرشق |
| `GET /api/logs` | آخر السجلات |
